# نظام تصميم وطباعة البطاقة الجامعية (`cerd`)

تطبيق ويب عربي (`RTL`) لتصميم ومعاينة وتصدير وطباعة البطاقات التعريفية (**جامعة العلوم الصحية**) بخط **Tajawal**، مع محرك مدمج لتوليد رمز الاستجابة السريعة (`QR Code`) وفق معيار `ISO/IEC 18004`، ودعم طباعة حتى `4` بطاقات (الوجه الأمامي والخلفي في نفس الصف) على ورق `A4` بالطول.

## 2. المزايا الرئيسية

### التصميم والمعاينة التفاعلية ([index.php](file:///c:/laragon/www/cerd/index.php))
- **أبعاد البطاقة:** `548×392px` بتصميم `SVG` متجهي وتدرجات لونية وزخارف غيلوش (`Guilloche`)، مع خط `Tajawal` في العرض والتصدير.
- **طرق عرض متعددة:** الوجهان معاً، عرض `3D` تفاعلي قابل للقلب، الوجه الأمامي فقط، أو الخلفي فقط، مع خلفيات عرض متعددة (`رخامي` / `داكن` / `فاتح`) وتحكم بالتكبير (`60%` إلى `125%`).
- **تخصيص التوقيع المعتمد:** اختيار نمط التوقيع (`silver` / `gold` / `cyan` / `dark`) أو رفع صورة توقيع مخصصة، مع أشرطة تمرير للحجم والموضع الأفقي والرأسي والدوران والشفافية.
- **تحسين الهوية البصرية:** إبراز عنوان المؤسسة بعيداً عن الحافة والمنحنى الأزرق، وتوسيط العلامة المائية لشعار الجامعة في المنطقة السفلية من الوجه الخلفي (`opacity: 0.16`).

### رمز الاستجابة السريعة (QR Code) والسيريال نمبر
- توليد فوري لرمز `QR` وفق `ISO/IEC 18004` (`UTF-8 Byte Mode`، مستوى تصحيح `L` للإصدارات `1..16`) بدون أي مكتبات خارجية أو اتصال بالإنترنت.
- تموضع الرمز والسيريال في أسفل يسار المساحة البيضاء بالوجه الأمامي (`left: 236px; bottom: 10px`) على خلفية بيضاء صلبة لقراءة موثوقة عبر كاميرا الهاتف.
- تشفير كامل بيانات حامل البطاقة عند المسح:
  - `الرقم` (السيريال المولد تلقائياً بصيغة `UHS-<السنة>-<hash6>` أو المخصص عبر `#inputEmpSerial`)
  - `الجهة` (الافتراضي: `جامعة العلوم الصحية`)
  - `الاسم`، `الإدارة` (الافتراضي: `إدارة تقنية المعلومات والاتصالات`)، `الوظيفة`، `الهاتف`، و`الإصدار`

### الطباعة على A4 بالطول والتصدير
- **نافذة طباعة A4 (`#printModal`):**
  - طباعة `1` إلى `4` بطاقات في الصفحة الواحدة (`A4 portrait`) مع معاينة حية لخانات الورقة.
  - تعديل بيانات وصورة وسيريال كل بطاقة على حدة قبل الطباعة.
  - **التحكم في عكس الاتجاه قبل الطباعة (`.print-mirror-btn`):**
    1. **عادي (غير معكوس):** طباعة بالاتجاه الطبيعي.
    2. **معكوس (النصوص فقط — الافتراضي):** يطبق `scaleX(-1)` مع `direction: rtl !important` و`text-align: right !important` على النصوص فقط مع بقاء الصورة والشعار والتوقيع ورمز `QR` دون عكس.
    3. **معكوس (كامل البطاقة):** عكس أفقي كامل للبطاقة (مناسب للطباعة الحرارية/المقلوبة).
- **تصدير PNG:** حفظ الوجهين معاً في صورة عالية الدقة عبر `exportHighResPng`.

## 3. قاعدة البيانات والترحيل (`SQL`)

يوفر ملف الترحيل [001_create_id_card_schema.sql](file:///c:/laragon/www/cerd/database/migrations/001_create_id_card_schema.sql) هيكلاً مرناً متوافقاً مع **MySQL 8.0+ / 9.x** مكوناً من الجداول التالية داخل قاعدة البيانات `cerd_cards`:

- `schema_migrations`: تتبع إصدارات الترحيل المطبقة.
- `card_templates` *(البيانات الثابتة)*: اسم المؤسسة، الشعار، التوقيع وإحداثياته (`sig_transform_json`)، نصوص الوجه الخلفي (`back_rules_json`)، وإعدادات التصميم (`layout_settings_json`).
- `departments`: دليل الإدارات والأقسام.
- `cards` *(البيانات الديناميكية)*: بيانات كل موظف وسيرياله الفريد وصورته وحمولة `QR`، مع عمودي `dynamic_fields` و`card_overrides_json` بصيغة `JSON` لإضافة حقول جديدة أو استثناءات دون تعديل البنية.
- `card_field_definitions` و`card_field_values`: تعريف وإدارة الحقول الديناميكية المخصصة القابلة للبحث والتحديد لإظهارها على البطاقة أو داخل `QR`.
- `print_batches` و`print_batch_items`: توثيق دفعات الطباعة (`A4 portrait`)، وضع العكس المستخدم، ونسخة مجمدة `snapshot_json` لكل بطاقة مطبوعة.

### تشغيل ملف الترحيل في Laragon
1. تأكد من تشغيل خدمة **MySQL** من لوحة تحكم **Laragon**.
2. نفّذ الأمر التالي في PowerShell:
   ```powershell
   & "C:\laragon\bin\mysql\mysql-8.4.3-winx64\bin\mysql.exe" -u root < "c:\laragon\www\cerd\database\migrations\001_create_id_card_schema.sql"
   ```

## 4. التشغيل والطباعة السليمة

1. شغّل **Apache** من **Laragon** ثم افتح في المتصفح:
   - المحرر التفاعلي: `http://localhost/cerd/index.php`
   - قالب الـ 4 بطاقات الثابت: `http://localhost/cerd/print4.php`
2. عند الطباعة أو الحفظ بصيغة `PDF` من المتصفح، احرص على:
   - تفعيل خيار **رسومات الخلفية (`Background graphics`)** لطباعة الألوان والتدرجات كاملة.
   - ضبط حجم الورق على **`A4`** والاتجاه على **عمودي (`Portrait`)**.
